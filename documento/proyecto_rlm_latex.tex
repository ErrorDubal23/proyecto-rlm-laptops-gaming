\section{Introduccion}

En la actualidad, el mercado de computadores portatiles ha experimentado un crecimiento exponencial, especialmente en el segmento de laptops orientadas al gaming. Estos dispositivos representan una inversion significativa para los consumidores, con precios que varian ampliamente segun sus especificaciones tecnicas. Comprender los factores que determinan el precio de una laptop gaming es fundamental tanto para consumidores como para fabricantes y distribuidores.

Desde la perspectiva de la ingenieria de sistemas, el analisis de datos permite identificar patrones y relaciones entre las caracteristicas tecnicas de un equipo y su costo en el mercado. El uso de tecnicas estadisticas como la regresion lineal multiple posibilita cuantificar el impacto de variables especificas ---como la memoria RAM, el peso del equipo, la marca del procesador y la tarjeta grafica--- sobre el precio final del producto.

Para este proyecto se utiliza el Laptop Price Prediction Dataset, un conjunto de datos que recopila informacion sobre especificaciones tecnicas y precios de laptops de diversas categorias. A partir de estos datos filtrados para el segmento gaming, se busca estudiar que variables influyen en el precio y en que medida lo hacen. Esto permitira comprender mejor el comportamiento del mercado de hardware y ofrecer una vision mas clara de los elementos que determinan el valor de un equipo de computo.

\subsection{Objetivo General}

Analizar y predecir los factores tecnicos y de marca que influyen en el precio de las laptops gaming, utilizando tecnicas de regresion lineal multiple.

\subsection{Objetivos Especificos}

\begin{enumerate}[leftmargin=2cm]
    \item Organizar el conjunto de datos para identificar las variables numericas y categoricas relevantes asociadas al precio de laptops gaming.
    
    \item Aplicar un modelo de regresion lineal multiple para predecir la relacion entre las variables seleccionadas y el precio del equipo.
    
    \item Interpretar los coeficientes del modelo para determinar cuales variables tienen el mayor impacto en el precio y que implicaciones tienen para la toma de decisiones en la adquisicion de equipos de computo.
\end{enumerate}

\section{Marco Teorico}

La regresion lineal multiple es una tecnica estadistica que permite modelar la relacion entre una variable dependiente continua y varias variables independientes. En el contexto de este proyecto, se utiliza para predecir el precio de laptops gaming a partir de sus especificaciones tecnicas.

La ecuacion general del modelo es:

\begin{equation}
    Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + ... + \beta_k X_{ki} + \varepsilon_i
\end{equation}

Donde $Y_i$ representa la variable dependiente (precio), $X_{ji}$ son las variables independientes, $\beta_j$ son los coeficientes de regresion y $\varepsilon_i$ es el termino de error.

Los supuestos del modelo incluyen: linealidad, independencia de residuos, normalidad de residuos, homocedasticidad y ausencia de multicolinealidad severa.

\section{Plan de Analisis}

El analisis se desarrollo siguiendo la metodologia de regresion lineal multiple. Primero se seleccionaron las variables cuantitativas y cualitativas del dataset relacionadas con el precio de laptops gaming. Luego se exploraron sus relaciones, se evaluo la correlacion, se generaron graficos y finalmente se estimo el modelo de regresion.

Para validar los resultados, se verificaron los supuestos de normalidad, homocedasticidad, independencia y ausencia de multicolinealidad. Todo el proceso siguio los pasos metodologicos del curso.

En este proyecto se utiliza el modelo con un proposito predictivo, es decir, el objetivo es predecir el precio de una laptop gaming a partir de las variables seleccionadas.

\section{Modelo de Regresion Lineal Multiple}

\subsection{Especificacion del Modelo}

El modelo de regresion lineal multiple estimado es:

\begin{equation}
    \log(Precio_i) = \beta_0 + \beta_1 \cdot RAM_i + \beta_2 \cdot Peso_i + \beta_3 \cdot CPU_i + \beta_4 \cdot GPU_i + \varepsilon_i
\end{equation}

Donde:
\begin{itemize}
    \item $\log(Precio_i)$: Logaritmo natural del precio en euros de la laptop $i$
    \item $RAM_i$: Memoria RAM en GB
    \item $Peso_i$: Peso del equipo en kg
    \item $CPU_i$: Variables dummy para la marca del procesador
    \item $GPU_i$: Variables dummy para la marca de la tarjeta grafica
    \item $\varepsilon_i$: Termino de error
\end{itemize}

Nota: Se utilizo la transformacion logaritmica en la variable dependiente (precio) para mejorar la normalidad de los residuos, un problema comun en datos de precios que presentan asimetria positiva.

\subsection{Interpretacion de Coeficientes}

Dado que el modelo utiliza $\log(Y)$, los coeficientes se interpretan como cambios porcentuales aproximados:

\begin{itemize}
    \item \textbf{RAM (GB):} Por cada aumento de 1 GB en la memoria RAM, el precio de la laptop aumenta aproximadamente un 3.3\%, manteniendo constantes las demas variables.
    
    \item \textbf{Peso (kg):} Por cada aumento de 1 kg en el peso del equipo, el precio aumenta aproximadamente un 13.7\%. Esto puede deberse a que laptops mas pesadas incluyen componentes mas robustos y sistemas de refrigeracion avanzados.
    
    \item \textbf{CPU Intel vs AMD:} Las laptops con procesador Intel tienen un precio aproximadamente un 17.7\% mayor que las equipadas con AMD, manteniendo constantes las demas variables.
    
    \item \textbf{GPU Nvidia vs AMD:} No se encontro una diferencia significativa en el precio entre laptops con GPU Nvidia y AMD (p = 0.421).
\end{itemize}

\section{Conclusiones}

\begin{enumerate}[leftmargin=1.5cm]
    \item El modelo de regresion lineal multiple desarrollado explica aproximadamente el 54.4\% de la variabilidad en el precio de las laptops gaming (R2 = 0.544), lo que indica un ajuste aceptable del modelo.
    
    \item La memoria RAM es el factor tecnico mas influyente en el precio de una laptop gaming. Por cada aumento de 1 GB en RAM, el precio aumenta aproximadamente un 3.3\%, manteniendo constantes las demas variables.
    
    \item El peso del equipo tambien tiene un impacto significativo en el precio. Laptops mas pesadas tienden a costar mas, posiblemente debido a la inclusion de componentes mas robustos y sistemas de refrigeracion avanzados necesarios para el rendimiento gaming.
    
    \item La marca del procesador (Intel vs AMD) muestra una diferencia significativa en el precio. Las laptops con CPU Intel tienen un precio aproximadamente un 17.7\% mayor que las equipadas con AMD.
    
    \item La marca de la tarjeta grafica (Nvidia vs AMD) no mostro una diferencia significativa en el precio (p = 0.421), lo que sugiere que ambas marcas compiten en rangos de precio similares en el segmento gaming.
    
    \item Los supuestos de normalidad (Shapiro-Wilk p = 0.552) e independencia (Durbin-Watson = 2.156) se cumplen satisfactoriamente. La heterocedasticidad detectada fue corregida mediante el uso de errores estandar robustos, una tecnica estandar en analisis de datos reales.
\end{enumerate}

\subsection{Recomendaciones}

\begin{itemize}[leftmargin=1.5cm]
    \item Para consumidores: Priorizar la cantidad de RAM al seleccionar una laptop gaming, ya que es el factor que mas impacta el precio y el rendimiento.
    
    \item Para fabricantes: Considerar que el peso del equipo puede ser un indicador de calidad percibida por los consumidores, justificando precios mas altos.
    
    \item Para futuros analisis: Ampliar el dataset para incluir mas variables como velocidad del procesador, tipo de almacenamiento (SSD vs HDD), y resolucion de pantalla.
\end{itemize}

    \item La aplicacion de correcciones robustas cuando los supuestos ideales no se cumplen completamente.

\end{itemize}
