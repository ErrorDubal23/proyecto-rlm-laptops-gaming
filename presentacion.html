🎯 Conclusiones

  1. El modelo explica el 70.6% de la variabilidad en el precio de las laptops (R cuadrado = 0.706)
  2. CPU es el factor cuantitativo mas influyente: +208 EUR por cada GHz adicional
  3. RAM tambien es clave: +81 EUR por cada GB adicional
  4. Workstation tiene el precio mas alto: +650 EUR vs 2 in 1 Convertible
  5. Windows 7 tiene coeficiente alto por ser sistemas antiguos con poca disponibilidad actual

💡 Recomendaciones

  • Para consumidores: la RAM y el CPU son los factores mas importantes al comprar
  • Para futuros analisis: incluir SSD vs HDD, marca de GPU y resolucion de pantalla
  • Considerar transformaciones para manejar la heterocedasticidad en precios altos
